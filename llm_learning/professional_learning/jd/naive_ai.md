岗位概述
作为公司智能体能力建设的核心成员，您将深度参与大模型 Agent 后训练方向的关键工作，推动模型在复杂推理、通用工具调用、多步任务执行与结果整合等关键能力上的持续演进。该岗位聚焦 Agent 能力的后训练与评测体系建设，重点围绕通用工具调用能力建模、评测体系搭建、效果分析与系统优化展开，并与数据合成、推理架构、强化学习等团队紧密协作，持续提升模型在真实复杂环境中的稳定性、泛化性与任务完成质量。
工作职责
后训练能力建设： 围绕 Agent 在真实任务中的能力短板，开展后训练方向的任务设计、能力拆解与效果优化，覆盖工具选择、参数生成、调用顺序规划、多步执行、执行反馈理解与结果整合等关键环节，持续提升模型在复杂工具环境中的任务完成能力。
评测体系建设：建设并完善 Agent 评测体系，充分利用开源评测框架，并结合模型能力目标进行选型、扩展与补充，围绕任务完成率、工具选择准确率、参数正确率、执行效率等核心指标，建立系统化、自动化的评测流程。
效果分析与优化： 基于评测结果和失败案例分析，定位模型、系统与工具接口中的关键瓶颈，沉淀误差归因方法，制定相应优化策略，形成“训练—评测—分析”的持续优化闭环。
工具调用系统协同： 参与工具调用接口与交互结构设计，结合渐进式披露等机制，优化模型在复杂工具集合下的调用稳定性、参数正确率与执行成功率，推动工具系统设计与模型能力建设协同演进。
数据策略协同： 与数据团队紧密协作，基于评测结果和能力缺口定义数据需求，参与关键任务、关键轨迹和评测样本设计，推动训练数据更贴近真实工具调用场景。
