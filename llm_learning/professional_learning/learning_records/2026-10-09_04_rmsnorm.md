## 1. 先定位：Norm 在 Transformer 中做什么？

Attention 让不同位置交换信息，FFN 加工每个位置的特征。Norm 则通常对每个 token 的隐藏向量调整尺度，为后续计算提供更稳定的输入。

线性投影、非线性与残差叠加会改变表示的大小。归一化可以减少后续子模块对输入整体尺度变化的敏感性，帮助优化；它不保证训练一定稳定，也不能简单概括为“防止梯度爆炸”。

现代模型中常见的 pre-norm block：

```text
输入 X ─────────────────────────┐
  ↓                             │
RMSNorm                         │
  ↓                             │
Attention                       │
  ↓                             │
相加 ←──────────────────────────┘
  │
  ├─────────────────────────────┐
  ↓                             │
RMSNorm                         │
  ↓                             │
FFN                             │
  ↓                             │
相加 ←──────────────────────────┘
  ↓
本层输出
```

对应公式：

$$
\begin{aligned}
H&=X+\operatorname{Attention}(\operatorname{RMSNorm}_1(X))\\
Y&=H+\operatorname{FFN}(\operatorname{RMSNorm}_2(H))
\end{aligned}
$$

两个 Norm 通常各有自己的参数。残差支路保留原来的输入，并不是先将整个残差流归一化，再拿它原样相加。某些架构采用不同顺序，不能将这张图当成所有 Transformer 的唯一结构。

### 1.1 为什么残差支路从 Norm 之前分出？

因为这里希望保留一条 **不经过 Norm、也不经过子模块的恒等路径**。设 $F$ 是 Attention 或 FFN，$N$ 是 Norm：

$$
y=x+F(N(x))
$$

可以理解为“原有表示 $x$ + 根据归一化输入计算出的更新”。Norm 为子模块调整输入尺度，但不直接替换残差流中的原有表示。

如果先归一化，再从归一化结果分出支路，得到的是另一种接法：

$$
z=N(x),\qquad y=z+F(z)
$$

此时两条支路都经过了 Norm，原始 $x$ 没有直接到达相加处。归一化并非无损编码，不能把它视为与第一种公式等价。

梯度上也能看到区别。以下用列向量记法，$J$ 表示导数矩阵，$I$ 是单位矩阵：

$$
\begin{aligned}
y=x+F(N(x))
&\quad\Rightarrow\quad
J_y=I+J_FJ_N\\
y=N(x)+F(N(x))
&\quad\Rightarrow\quad
J_y=(I+J_F)J_N
\end{aligned}
$$

第一种有一项 $I$，提供不必经过 Norm 与子模块导数的直接梯度路径。第二种没有绕开 Norm 的路径。多层堆叠时，pre-norm 的这种设计常有利于优化，但不保证所有方向上的梯度都不消失，也不保证绝不爆炸。

不要把第二种接法称为标准 post-norm。标准 post-norm 是：

$$
y=N(x+F(x))
$$

它在残差相加之后归一化。它的残差支路也从子模块之前分出，但相加后的结果仍要经过 Norm，因此层与层之间的直接路径中包含归一化。

一句话：

> **Pre-norm 把“稳定子模块输入”和“保留原始残差通路”分开处理；这是一种架构选择，不是 Norm 必须遵守的连接规则。**

## 2. 最重要的形状问题：沿哪个轴归一化？

对常见输入：

$$
X\in\mathbb R^{B\times n\times d_{\text{model}}}
$$

标准 token-wise Norm 沿最后的特征轴计算，即固定样本与 token 后，处理这个 token 的整个隐藏向量。

例如 $B=2,n=3,d_{\text{model}}=4$：

```text
样本 0
  token 0：[a,b,c,d] → 单独计算自己的归一化尺度
  token 1：[e,f,g,h] → 单独计算自己的归一化尺度
  token 2：[i,j,k,l] → 单独计算自己的归一化尺度

样本 1
  各 token 同样独立处理
```

不是把三行 token 混在一起计算统计量，也不是将两个样本一起计算。

$$
[B,n,d_{\text{model}}]
\ \longrightarrow\ \operatorname{Norm}\
\longrightarrow [B,n,d_{\text{model}}]
$$

每个 token 有自己的统计量；同一个 Norm 模块的可学习特征缩放参数通常在不同 token、样本间共享。

“LayerNorm”中的 Layer 不意味着对整个 Transformer 层的所有样本与位置统一求均值。具体归一化轴由配置决定；这里讨论的是 LLM 中常见的最后一个隐藏特征轴。

## 3. RMSNorm：按均方根缩放

### 3.1 均方根是什么？

RMS 是 Root Mean Square，步骤就是：

> 每个分量平方 → 取平均 → 开平方。

对一个 token 的向量 $x=[x_1,\ldots,x_d]$，这里 $d=d_{\text{model}}$：

$$
\operatorname{RMS}(x)
=\sqrt{\frac{1}{d}\sum_{r=1}^{d}x_r^2}
$$

它反映分量的整体大小，避免正负值在求平均时互相抵消。它不是向量的普通算术均值。

与欧几里得长度的关系：

$$
\operatorname{RMS}(x)=\frac{\|x\|_2}{\sqrt d}
$$

### 3.2 RMSNorm 的公式

常见标准形式为：

$$
\boxed{
y_r=\gamma_r\,
\frac{x_r}{\sqrt{\frac1d\sum_{s=1}^{d}x_s^2+\epsilon}}
}
$$

- 分母是整个 token 向量的同一个标量，而不是每个分量各自一个分母。
- $\epsilon>0$ 用于数值稳定，尤其避免全零向量时除以零；具体值由模型实现决定。
- $\gamma_r$ 是第 $r$ 个特征的可学习缩放参数，通常初始化为 1。
- 标准 RMSNorm 通常不做减均值，也不使用加法偏置 $\beta$；具体变体可能不同。

一个 Norm 的 $\gamma$ 通常有 $d$ 个参数，不随 batch size 或 token 数增加。

### 3.3 完整数字例子

取：

$$
x=[1,1,3,3]
$$

为方便手算，暂时忽略 $\epsilon$，并令所有 $\gamma_r=1$：

$$
\operatorname{RMS}(x)
=\sqrt{\frac{1+1+9+9}{4}}=\sqrt5
$$

因此：

$$
y=\frac{[1,1,3,3]}{\sqrt5}
\approx[0.4472,0.4472,1.3416,1.3416]
$$

观察：

- 输出仍然是 4 维。
- 分量之间的比例不变，仍然都是正数。
- 输出均值不为零。
- 在此理想条件下，输出的均方根为 1。

忽略 $\epsilon$ 与 $\gamma$ 时，RMSNorm 是按一个正标量缩放向量，保持方向。加入各维不同的 $\gamma_r$ 后，方向与分量比例可以变化，所以不能说“完整 RMSNorm 总是保持方向”。

## 4. LayerNorm：先减均值，再按标准差缩放

对同一个 token：

$$
\mu=\frac1d\sum_{r=1}^{d}x_r
$$

$$
\sigma^2=\frac1d\sum_{r=1}^{d}(x_r-\mu)^2
$$

这里除以 $d$，不是无偏样本方差估计中的 $d-1$。它是归一化操作使用的特征方差。

标准带仿射变换的 LayerNorm：

$$
\boxed{
y_r=\gamma_r\frac{x_r-\mu}{\sqrt{\sigma^2+\epsilon}}+\beta_r
}
$$

仍取 $x=[1,1,3,3]$，忽略 $\epsilon$，令 $\gamma=1,\beta=0$：

$$
\mu=2,\qquad \sigma^2=1
$$

$$
y=[-1,-1,1,1]
$$

与 RMSNorm 对比：

| | LayerNorm | RMSNorm |
|---|---|---|
| 是否减均值 | 是 | 否 |
| 归一化分母 | 中心化后的标准差，加稳定项 | 未中心化的均方根，加稳定项 |
| 理想例子输出 | $[-1,-1,1,1]$ | $[1,1,3,3]/\sqrt5$ |
| 标准可学习参数 | $\gamma$ 和 $\beta$，可按配置关闭偏置等 | 通常只有 $\gamma$ |
| 是否保持形状 | 是 | 是 |

LayerNorm 的“均值为零、方差为一”描述的是忽略稳定项、仿射变换之前的归一化结果。完整输出经过 $\gamma,\beta$ 后，不保证仍有这些统计性质。

## 5. 为什么可以不减均值？

两者都能调节尺度，但是否消除共同的偏移不同。

对输入每个分量都加常数 $c$：

$$
x'=x+c\mathbf1
$$

LayerNorm 的中心化会消除这个偏移：$x'-\mu'=x-\mu$。在相同参数下，标准 LayerNorm 对这种共同平移不敏感。

RMSNorm 不减均值，因此一般不会消除这种偏移。它主要保留对整体正比例缩放的近似不敏感性：

$$
\frac{ax}{\operatorname{RMS}(ax)}
=\frac{x}{\operatorname{RMS}(x)},\qquad a>0
$$

此等式忽略 $\epsilon$，且输入非零；真实稳定项会使这种不变性不再精确。

RMSNorm 的研究表明，在所研究的任务中，去掉中心化仍可保持与 LayerNorm 相近的效果，并简化计算。现代一些 LLM 因此采用 RMSNorm，但它不是所有任务必然优于 LayerNorm 的定理。

它减少了均值中心化相关操作；实际速度收益取决于实现与硬件，本节不做 kernel 性能专项。

## 6. 与 BatchNorm、Softmax 和 RoPE 不要混淆

| 操作 | 本节关注的作用 | 常见归一化 / 处理范围 |
|---|---|---|
| RMSNorm / LayerNorm | 调整隐藏表示尺度 | 每个 token 的特征维度 |
| BatchNorm | 典型训练设置下按特征 / 通道聚合 batch 等轴的统计量 | 不同于这里逐 token 计算 |
| Attention softmax | 分配信息读取权重 | 每个 query 的可读 key 位置 |
| RoPE | 将位置作用引入匹配 | Q、K 的二维特征配对 |

RMSNorm 输出不要求非负，也不要求分量总和为 1。它不是将隐藏状态变成概率。

标准 token-wise LayerNorm / RMSNorm 在训练和推理时都用当前输入计算统计量，不像常见 BatchNorm 推理那样依赖训练期间的 running mean / variance。因此一条请求不会仅因换了同批的其他请求而改变其 Norm 统计量。

## 7. 常见问题与边界

**会破坏 KV Cache 吗？**

不会仅因使用这种 Norm 而破坏历史复用。它不跨 token 计算统计量，新增未来 token 不会修改旧 token 的 Norm 结果；前提仍是模型与位置规则等保持一致。

**归一化后是不是信息都变成一样了？**

不是，但它也不是无损编码。例如忽略稳定项时，正比例缩放的两个向量经 RMS 归一化后相同，说明整体尺度信息被消除了。方向与分量间关系仍可保留，残差路径还保留另一条信息通路。

**能随意将训练好的 LayerNorm 换成 RMSNorm 吗？**

不能假定无损替换。它们的函数不同，模型权重是在原有结构下训练的。修改需要训练适配与评测，不是推理时随便切换的开关。

**为什么模型最后还有一次 Norm？**

常见 pre-norm 模型的残差流在多层叠加后，最后再做 Norm，为 LM Head 提供归一化后的表示。具体是否存在及采用何种 Norm 取决于架构。

**反向传播只是除以一个常数吗？**

不是。分母本身依赖输入的各个分量，梯度也通过分母传播。一个 token 内的特征因此在梯度计算中有关联，但这不意味着不同 token 被混合。

## 8. 可选自测与总结

1. 对 $[B,n,d_{\text{model}}]$，标准 token-wise RMSNorm 沿哪个轴计算？
2. 输入全部为正，RMSNorm 是否一定让输出均值变成零？
3. 为什么 LayerNorm 公式用方差，而 RMSNorm 用平方均值？
4. 增大 batch size 会增加同一个 Norm 的参数量吗？

<details>
<summary>参考答案</summary>

1. 最后的隐藏特征轴，固定样本与 token 后分别计算。
2. 不会主动中心化；若 $\gamma=1$，正输入归一化后仍为正，均值不为零。
3. LayerNorm 先减均值，RMSNorm 直接衡量未中心化输入的幅度；平方均值不等于方差，二者相差均值的平方。
4. 不会，各位置和样本复用同一模块的特征参数。

</details>

一句话总结：

> LayerNorm 和 RMSNorm 通常都逐 token 调整特征尺度，保持张量形状；LayerNorm 先中心化再缩放，RMSNorm 不减均值，直接按均方根缩放。它们不同于注意力概率归一化，也不负责跨位置交换信息。
