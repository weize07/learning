# 5. 合成数据：从生成成功到可信规模化

> 2026-10-21 补充；待阅读。未调用教师模型或生成真实训练集。
> [专题入口](README.md) · 前一章：[配比与语言](2026-10-21_04_data_mixture_and_multilingual_balance.md) · 下一章：[多模态数据](2026-10-21_06_multimodal_data_alignment.md)

## 1. 是什么：本章补验证工程，不重讲蒸馏损失

已有 [蒸馏与合成数据](../2026-10-11_02_distillation_and_synthetic_data.md)覆盖文本示范、软分布、on-policy 指导、来源与独立评测。这里关注：怎样批量生产，同时避免错误、重复和验证器偏差被放大。

合成流程有三种身份：生成器提出候选，验证器提供有限证据，数据发布者决定是否收录。生成模型自称正确，不等于经过验证。

## 2. 为什么要做：产量提升可能只是重复错误

大量相似 prompt 可能只扩增模板；只保留验证器容易判定的内容，会使困难任务消失。同一个模型生成和裁判还可能重复相同偏见。

因此要统计“独立、可用、覆盖目标的训练信息”，不只统计生成条数或平均 judge 分数。

## 3. 怎么做：覆盖计划 → 候选 → 多层验证 → 发布

### 3.1 先冻结种子来源和划分

先按文档 / 任务族分 train / dev / test，只用训练来源生成训练样本；记录父记录、教师与 prompt 版本、参数、生成时间、验证结果和派生组。

覆盖计划至少分任务、难度、语言、证据充足性与失败类型。对稀缺格子定向生成；不是不断增加已经饱和的简单样本。

### 3.2 验证器按证据能力分层

| 层 | 能提供什么证据 | 无法保证什么 |
|---|---|---|
| Schema / 协议 | 字段、类型、引用 ID 和工具参数格式 | 内容正确、业务合法 |
| 确定性检查 | 算术、约束、数据库核对、编译 | 任意开放问答的完整正确性 |
| 隔离环境执行 | 测试通过、动作后状态满足条件 | 测试之外的正确性、真实环境全部行为 |
| 证据支持检查 | 答案关键事实能追到允许使用的资料 | 资料本身绝对真实、没有遗漏 |
| 模型 judge | 根据 rubric 筛选主观和复杂属性 | 不受风格、位置、长度或同源错误影响 |
| 人工复核 | 校准标准、处理分歧和风险样本 | 未抽到样本也可靠 |

代码只通过教师自己写的测试，可能是共同出错；用独立设计的用例核验。最终答案正确也不证明中间推理正确，尤其不应把不可验证的长解释自动当作优质监督。

调用模型之前先核对数据外发权限和服务使用条款；执行生成代码只在获准的隔离环境中进行。

### 3.3 校准验证器，而非盲设分数门槛

建立与生成调参分离的人工校准集，含正确、错误、边界与难题，检查：

- 被接受样本中，有多少实际错误：决定训练污染风险。
- 被拒绝样本中，有多少本应保留：决定覆盖损失。
- 每个语言 / 领域 / 难度的差异：防止整体分数掩盖弱项。
- 位置交换、答案长度变化是否改变偏好：发现 judge 偏置。

高风险项使用硬规则；模糊项进入复核队列。阈值由容许风险与成本决定，不使用统一的“judge 超过 8 分”。

### 3.4 批量生产需要幂等与版本

一个逻辑任务绑定种子、模板、教师配置和输出槽位。重试使用同一任务身份，成功候选不可因网络重试重复入库；要增加多样性则显式新建采样槽位。

保留失败与拒绝原因，按成本和覆盖缺口决定重试 / 修复；设置预算，不因失败而无限请求。教师或验证器升级后，新旧版本分别统计，不把分数直接混合。

### 3.5 成本账按最终可用结果计

$$
C_{\text{accepted-token}}
=\frac{C_{\text{generation}}+C_{\text{verification}}+C_{\text{human}}+C_{\text{processing}}}
{T_{\text{accepted}}}
$$

分母是去重、验证后可用于目标训练的 token；SFT 应明确是否只计监督 token。分母为零时成本无可用估计，应报告“零可用产出”，不能记成零成本。

这个指标也不是最终目标：便宜的一百万重复 token 未必比昂贵的困难样本有用。还需报告新增覆盖，以及同预算模型效用。

## 4. 为什么这么做：困难样本不应只靠删除解决

对于高失败率任务，可改善证据、分解问题、人工修复或换独立验证方式；不要仅降低难度直到通过率变高。保留失败类别用于重新采集，但不能把错误答案作为 SFT 正例。

至少比较可靠人工 / 已验证数据基线、额外合成方案和对应成本。若同时增加数据量、教师规模和训练步数，只能说明组合方案有效，不能单独归因于某个生成技巧。

## 5. 可选练习

以自拟的操作规范问答设计一批候选，包含可答、缺证据、矛盾和版本不符四种类型。写出每层验证器能检查什么，不能检查什么。

验收：

- 每条候选有训练来源和独立划分信息。
- 缺证据样本不会因为表达流畅而通过。
- 接受 / 拒绝集均有校准设计，困难覆盖有单独统计。
- 重试不重复发布，失败有原因和预算终止。
- 不把生成量、通过率或训练 loss 当作模型收益证明。
