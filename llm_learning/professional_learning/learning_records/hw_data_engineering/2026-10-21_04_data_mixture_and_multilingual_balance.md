# 4. 预训练配比优化与多语言均衡

> [专题入口](README.md) · 前一章：[质量治理](2026-10-21_03_quality_validation_and_governance.md) · 下一章：[合成验证](2026-10-21_05_synthetic_data_verification.md)

## 1. 是什么：在有限训练预算内分配有效曝光

已有 [SFT 混合采样](../2026-10-10_03_data_distribution_and_sampling.md)讲了样本占比、监督 token、温度采样和独立评测。本章新增的是预训练多域 / 多语言约束，不重复基础推导。

配比不是“哪类资料最多就学哪类最多”，而是选择各域 / 语言在训练中消耗多少预算。目标能力、可用独立内容、重复风险与计算成本共同约束配方。

## 2. 为什么要做：条数、字符数与 token 数不等价

长文一条可以包含短句数百倍的 token；同样长度的两种语言也可能产生不同 token 数。按文件数平衡，模型实际获得的曝光未必平衡。

多语言问题还包括：语种误识别、混合语言、翻译腔、文化和知识覆盖不同、非拉丁文字被清洗损坏。不能只把中文比例上调就宣称完成多语言均衡。

## 3. 怎么做：先做画像，再做可解释配方

### 3.1 域 × 语言 × 质量的交叉画像

记录每个非空分组的独立 token 数、文档数、长度、重复度、来源与质量分布。语言识别保留置信度和混合语言状态，抽查短文本、代码夹杂与低资源语言。

避免只用来源站点推断语言；翻译数据保留原文父组，不能把原文和译文拆到训练、测试两边。

Tokenizer 统计包括 token / 字符或 token / 字节、截断率、序列利用率。这些只能说明表示成本，不是跨语言语义难度的统一度量。

### 3.2 用 token 预算估计重复曝光

设质量过滤和去重后，第 $i$ 组有 $U_i$ 个可用 token，计划总消费 $B$ 个 token，分配比例为 $w_i$，且 $\sum_i w_i=1$：

$$
B_i=Bw_i,\qquad E_i=\frac{Bw_i}{U_i}
$$

$E_i$ 是等效数据遍数，近似反映重复曝光；它不保证每篇文档恰好出现这么多次。文档采样、截断和 packing 会带来差异，必须记录实际消费。

教学例子：A 有 8000 万独立 token，B 有 2000 万；预算为 2 亿，二者各占 50%。A 的等效曝光为 1.25 遍，B 为 5 遍。B 得到更多预算，但没有凭空增加知识；可能需要补可靠来源，而非继续重复。

预训练常按有效 token 配预算；SFT 还需区分上下文 token 与监督 token。多模态还要考虑视觉 / 音频表示和分辨率，不能套一个文本 token 口径比较所有成本。

### 3.3 温度采样是基线，不是最优证明

对非空数据组，可从以下候选起步：

$$
p_i=\frac{U_i^\alpha}{\sum_j U_j^\alpha},\qquad 0\leq\alpha\leq1
$$

如果 $U_A:U_B=4:1$，则 $\alpha=1$ 时是 80% / 20%；$\alpha=0.5$ 时约为 66.7% / 33.3%。这是定义在 token 供给量上的候选权重；若实现按文档抽样，需校正平均长度并验证实际 token 占比。

增大低资源组权重前检查其质量、独立内容量与重复上限。组的划分也要固定，不能通过人为拆出更多小组改变其总权重。

### 3.4 怎么比较配方

| 对照 | 只改变什么 | 要验证什么 |
|---|---|---|
| A：基础配方 | 基线 | 原始能力和语言短板 |
| B：语言重平衡 | 语言预算 | 低资源语言是否受益、主语言是否退化 |
| C：定向补数据 | 缺口来源 / 难度覆盖 | 新信息是否优于重复旧样本 |
| D：质量重加权 | 合格池内的质量权重 | 质量收益是否以覆盖损失为代价 |

同一次因果对照尽量保持起始 checkpoint、训练目标、优化器和预算口径一致。可以先用小模型 / 短程训练筛选，再在目标设置复核；代理实验排名不保证在大规模训练中不变。

开发集用于调配方，最终测试集不能被反复用于选权重。报告分语言、分领域结果，至少保留主语言 / 原有能力回归；固定汇总权重，不随训练配方改变测试分布。

跨语言 tokenization 不同，原始 perplexity 不宜直接作为公平的跨语言排名。结合相同任务定义的下游指标、长度成本和语言内变化，解释模型收益。

### 3.5 数据驱动方法放在基线之后

DoReMi 可作为进阶阅读：用代理模型和域重加权寻找配方，再用于目标训练。重点理解权重依据、参考损失和代理到目标的迁移，而不是记住方法名。

“某域 loss 高就一直加权”不是可靠规则：高 loss 可能来自噪声、分词差异或不可学习内容；还需看边际收益、质量和其他域损失。

## 4. 为什么这么做：均衡不是每种语言一模一样

均分可提高小语种曝光，却可能重复低质量内容；按原始量分配高效，但可能让强势语言主导。合理策略应明确目标能力和底线，再用受控实验寻找折中，而不是把某个 $\alpha$ 当行业标准。

## 5. 可选练习

设计两种语言、两个领域的预算表，写清独立 token、计划占比、等效曝光和评测指标。

验收时检查：

- 计划比例和实际消费比例分开报告，总预算可核对。
- 某语言源数据不足时，有降低预算或补采方案，不无限重复。
- 语言识别未知样本单独处理，不被默默归入主语言。
- 翻译和改写继承父组，未跨 train / dev / test。
- 候选配方有未受益或退化时的停止条件。
