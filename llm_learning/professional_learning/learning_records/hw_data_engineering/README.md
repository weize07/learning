# 大模型数据工程补充专题：从语料生产到模型收益

**结论：现有学习记录偏重模型原理、后训练与 Agent 应用，尚未形成面向基础模型的数据生产主线。** 最明显的专项缺项是预训练语料管线、大规模去重、多语言均衡、多模态数据；质量治理与数据飞轮需要系统串联。配比、合成 / 蒸馏、Agent 轨迹已有基础，本专题只补工程深化部分。

编写日期：2026-10-21。依据：[岗位说明](../../jd/hw_candy.md)、[个人经历](../../experience/zewei_en_202610.md)和[每日学习索引](../topics_by_date.md)，并核对下表所列相关教材正文。

**状态：补充材料已提供，全部待阅读；未执行数据处理、模型训练或效果实验。** “未见专项记录”不等于你从未学习或没有工作经验，也不把旧教材存在视为已经掌握。

**先看训练总图（2026-10-22 新增）**：[现代 LLM 训练流水线：阶段、能力域与典型工作](../2026-10-22_01_llm_training_pipeline_and_capability_map.md)。该篇解释数据进入哪种训练、各阶段增强什么以及怎样验收；本专题再展开数据生产实现，不把数据管线当作完整训练流水线。

## 3. 如何连接已有经历，而不是从零重学

| 已有经历（简历记载） | 可迁移的能力 | 本专题需要补的差异 |
|---|---|---|
| Spark / Kafka、分布式 ETL | 分区、吞吐、重试、增量处理 | 面向语料的全局去重、token 预算和质量分布 |
| Spark LSH 检索 | 近似候选召回和大规模连接 | 文本 shingle / MinHash、重复簇、误删与跨集合污染 |
| Purview、数据血缘 | 来源管理、依赖追踪和治理协作 | 从原始来源到合成子样本、数据版本和训练产物的追踪 |
| 合成数据、benchmark、教师模型微调 | 覆盖设计、校验、模型对照 | 预训练域 / 语言混合、多模态和规模化验证 |
| 图像分类、语音处理 | 模态处理与模型工程 | 图文语义配对、视觉指令、音视频同步的训练数据质量 |

这些是学习衔接点，不自动证明已有大规模基础模型语料或视觉语言模型数据实践。现有简历也没有给出这些专项的完整验证证据。

## 4. 范围和证据边界

- 本次新增一个专题目录，并在每日索引和主索引增加入口；不替换当前 Agent 实践任务。
