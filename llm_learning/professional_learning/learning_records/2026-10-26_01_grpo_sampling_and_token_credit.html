GRPO：多份回答怎么生成，整段奖励怎样传给 token？

自回归采样 → 组内优势 → token 的 log-prob → 生成模型参数

sourceDeepSeekMath §4.1.1–4.1.3

问题 1：是的，通常按每一步的 softmax 分布采样。 同一问题重复采样，得到多条完整回答。

问题 2：结果奖励式 GRPO 将序列优势用于所有有效回答 token。 它加权各 token 的 log-prob，不会判断每个 token 分别贡献了多少奖励。

A

同一个问题，如何生成 G 份不同回答？

设 x 包括相同的问题与允许提供的上下文。 用本轮采样策略 πold，重复生成 G 次。 每份回答都有自己的已生成前缀。

第 i 个回答的第 t 步：

zi,t=LMold⁡(x,yi,<t)
pi,t(v)=softmax⁡(zi,tτ)v,yi,t∼Categorical⁡(pi,t)

zi,t 是词表 logits，τ>0 是温度。 采样到一个 token 后，将它加入该回答的前缀。 然后继续下一步，直到 EOS 或长度上限。

  • 开始时前缀相同，下一 token 分布也相同。
  • 独立随机抽样，仍可能选到不同 token。
  • 前缀分叉后，后续分布通常也会不同。
  • 回答可以重复；采样不保证每份都不同。

这不是训练 G 个模型，也不是强制枚举不同答案。 若使用确定性的 greedy 解码，重复生成通常相同。 实际采样还可以配置 top-p 或 top-k。

以下数学推导取温度为 1，且不做截断采样。 其他设置下，要核对采样分布与训练 log-prob 的一致性。 不能忽略温度或截断造成的分布变化。

B

一个序列奖励，先变成一个序列优势

对每份完整回答评分：

Ri=R(x,yi),i=1,…,G

奖励可以来自规则、测试或 Reward Model。 GRPO 不要求一定使用学习型 RM。

在同一问题的组内计算：

R‾=1G∑j=1GRj,σR=1G∑j=1G(Rj−R‾)2
Ai=Ri−R‾σR+εnorm

这里为手算采用总体标准差。 实现也可能使用其他标准差定义或缩放方式。

结果奖励式 GRPO 的关键分配规则是：

Ai,t=Ai,t=1,…,Ti

即：同一回答的每个有效生成 token，共享一个优势系数。

例如，两份回答的奖励为 [1,0]。 忽略稳定项时，均值为 0.5，标准差为 0.5。 于是优势为 [+1,−1]。

回答 序列优势 每个有效回答 token 使用的系数
回答 1 +1 +1,+1,…,+1
回答 2 −1 −1,−1,…,−1

不是先把 reward 拆成逐 token 的正确性标签。 若所有奖励相同，稳定处理后优势为零。 此时组相对策略项无信号，KL 项仍可能有梯度。

C

为什么用 token 的 log-prob，就能训练整段回答？

自回归模型的完整回答概率满足：

πθ(yi|x)=∏t=1Tiπθ(yi,t|x,yi,<t)

取对数后，乘积变成求和：

log⁡πθ(yi|x)=∑t=1Tilog⁡πθ(yi,t|x,yi,<t)

基础策略梯度的来源是：

∇θ𝔼y∼πθ[R(y)]=∑yR(y)∇θπθ(y|x)=𝔼[R(y)∑t∇θlog⁡πθ(yt|x,y<t)]

这要求奖励本身不直接依赖待求导的策略参数。 还需满足交换求和与求导的条件。 这是基础原理，不是完整 GRPO 目标。

注意：不需要对 reward 求导，也不需要对采样操作求导。 奖励是固定权重；可微路径是策略的 log-prob。

为看清方向，先看一个加权 log-prob 教学形式：

ℓi=−AiTi∑t=1Tilog⁡πθ(yi,t|x,yi,<t)
∇θℓi=−AiTi∑t=1Ti∇θlog⁡πθ(yi,t|x,yi,<t)

同一个 Ai 乘上每个 token 自己的梯度，再相加。 1/Ti 是此处采用的长度归约，不是逐 token 的功劳估计。

这个教学形式不是完整 GRPO loss。 在新旧策略相同、裁剪未激活且忽略 KL 时，其梯度与对应策略项一致。 组内归一化也不应直接宣称是精确无偏的优势估计。

D

信号真正进入 softmax 时，梯度长什么样？

固定某一条已采样回答。 令：

pt(k)=πθ(k|x,y<t)=softmax⁡(zt)k

对上一节教学损失求导：

∂ℓi∂zt,k=AiTi(pt(k)−𝟏[k=yi,t])

这里暂时省略组平均与问题 batch 的公共因子。 对真正采样到的那个 token：

∂ℓi∂zt,yi,t=AiTi(pt(yi,t)−1)
  • Ai>0：该 logit 的梯度为负，梯度下降倾向提高它。
  • Ai<0：该 logit 的梯度为正，梯度下降倾向降低它。
  • 其他词表 logit 也有梯度，因为 softmax 联合归一化。

同一个优势，不代表每个 token 的梯度数值相同。

以下是三 token 回答的教学算例，Ti=3。 表中给出已采样 token 的 logit 梯度。

位置 当前已采样 token 概率 若 Ai=+1 若 Ai=−1
t=1 0.8 −0.066667 +0.066667
t=2 0.5 −0.166667 +0.166667
t=3 0.2 −0.266667 +0.266667

梯度继续经过 LM head、隐藏状态与 Transformer 各层。 所有回答、所有位置的参数梯度最终累加。 共享参数、裁剪与 KL 可能改变单个 token 的实际更新结果。

E

完整 GRPO 还加入新旧概率比、裁剪与 KL

DeepSeekMath 原始 token 级目标使用：

ρi,t=πθ(yi,t|x,yi,<t)πold(yi,t|x,yi,<t)
Ci,t=min⁡(ρi,tAi,clip⁡(ρi,t,1−ϵclip,1+ϵclip)Ai)

写成需要最小化的损失：

ℒGRPO=−1G∑i=1G1Ti∑t=1Ti(Ci,t−βKi,t)

Ki,t 是相对参考策略的 KL 惩罚或相应估计。

对象 本轮中的作用
πold 生成这批回答；提供固定的分母 log-prob
πθ 当前待更新的生成策略
πref 提供偏离约束；不是概率比中的 old
Ai 由组内奖励算出的固定训练信号

未进入裁剪饱和区时，策略项的 token 梯度包含：

−Aiρi,tTi∇θlog⁡πθ(yi,t|x,yi,<t)

新旧参数相同时，ρi,t=1。 但分母固定，分子可训练，所以梯度仍可非零。 这时就得到前两节所示的加权 log-prob 梯度。

裁剪饱和后，该 token 的这部分策略梯度可能为零。 KL 项仍可有梯度。 因此，“每个 token 都分到相同优势”不等于“每个 token 都被同幅度更新”。

以上采用原始逐回答长度平均。 现代实现可能改变长度归约、优势缩放或 KL 设置。 逐 token 裁剪也不等价于整段序列概率比裁剪。

F

训练时怎样实际算出所有 token 的梯度？

生成与训练是两个阶段，不是边抽样边穿过离散 token 回传。

采样阶段通常不保留用于 BP 的整条生成计算图。 评分结果与优势在策略更新时停止梯度。

训练阶段，将已采样文本作为固定数据。 用 teacher forcing 和 causal mask 重新前向。 这样可以并行计算各位置的条件 log-prob。 此处不需要重新采样下一 token。

只取各位置实际采样到的 token 的 log-prob。 然后用优势、概率比和 mask 构造损失。

  • prompt token 不作为生成动作计入此损失。
  • padding token 不计入此损失。
  • EOS 与超长截断的处理依赖明确的训练协议。

prompt 虽然没有直接的动作损失，仍参与条件计算。 它对应的可训练表示也可能通过注意力路径收到梯度。

G

这能精确判断哪一步推理有功劳吗？

不能。结果奖励式 GRPO 做的是较粗的信用分配。

奖励高的回答可能包含错误推理或无用文字。 这些位置仍会使用同一个正优势。 奖励低的回答也可能包含大量正确内容。 这些位置仍会使用同一个负优势。

同一个词出现在不同前缀下，是不同的条件动作。 模型不是在全局“奖励这个词”或“惩罚这个词”。 它优化的是特定前缀下选择这个 token 的倾向。

大量样本能提供统计性的区分信号。 但它不保证自动定位真正有因果作用的推理步骤。 过程奖励或逐前缀价值估计可提供不同粒度的信号。 这些设计不等同于这里的单一结果奖励形式。

与你前面讨论的 RM 训练，区别在这里：

训练对象 可微损失路径 被更新的模型
成对 RM 训练 偏好损失 → 奖励分数 → RM 参数 评分模型
GRPO 策略训练 固定优势 × token 概率项 → 策略参数 生成模型

GRPO 不需要把奖励模型的梯度穿过离散回答传给生成模型。
