# 05 · 蒸馏：为什么小模型仅做 SFT，也能学到推理行为？

- 编写日期：2026-10-23；状态：待阅读，未运行学生模型。
- 导航：[上一章](2026-10-23_04_r1_pipeline_and_data.md) · [专题入口](README.md) · [下一章：评测](2026-10-23_06_evaluation_and_evidence.md)。
- 主要证据：[v1 §2.4](https://arxiv.org/html/2501.12948v1#S2.SS4)、[§3.2 表 5](https://arxiv.org/html/2501.12948v1#S3.SS2)、[§4.1 表 6](https://arxiv.org/html/2501.12948v1#S4.SS1)。

## 1. 这篇论文里的蒸馏具体是什么？

**论文事实**：用 §2.3.3 中整理的约 800k 样本，直接微调 Qwen / Llama 模型。所报告的这批学生模型只做 SFT，没有再进行 RL。

这是**文本 / 行为蒸馏**：学生学习精选回答的 token，不要求读取教师每一步的完整概率分布。

教学损失写成：

$$
\mathcal L_{\mathrm{SFT}}(\phi)=
-\mathbb E_{(q,y)\sim D_{\mathrm{curated}}}
\sum_{t\in\mathrm{supervised}}
\log p_\phi(y_t\mid q,y_{<t}).
$$

具体按样本还是 token 平均、哪些位置被监督，需要实现明确。这个公式解释机制，不冒充报告完整的训练配置。

## 2. 什么不是这里的蒸馏？

| 容易误读的说法 | 正确区分 |
|---|---|
| 把 671B 的层删到 7B | 学生有自己的架构与初始化权重 |
| 学生必须与教师共享 tokenizer | 文本可以分别分词，仍可学习 |
| 训练时必须在线请求教师 logits | 本文是精选文本 SFT，不要求这种接口 |
| 学生也经历了四阶段 RL | 本文报告的学生只做 SFT |
| 所有数据都由最终发布 R1 一次生成 | 方法节指向多阶段整理的 800k 集合，其中还有通用数据来源 |

论文摘要 / 讨论常用“蒸馏 R1 输出”概括流程；要了解数据血缘，应以方法节展开说明为准。

## 3. 六个学生从哪里出发？

下表按论文 §2.4 与官方模型清单核对。结果仅节选表 5 的 AIME 2024 pass@1。

| 发布模型 | 初始化 checkpoint | AIME pass@1 |
|---|---|---:|
| R1-Distill-Qwen-1.5B | Qwen2.5-Math-1.5B | 28.9% |
| R1-Distill-Qwen-7B | Qwen2.5-Math-7B | 55.5% |
| R1-Distill-Llama-8B | Llama-3.1-8B | 50.4% |
| R1-Distill-Qwen-14B | Qwen2.5-14B | 69.7% |
| R1-Distill-Qwen-32B | Qwen2.5-32B | 72.6% |
| R1-Distill-Llama-70B | Llama-3.3-70B-Instruct | 70.0% |

注意 Llama-70B 起点是 Instruct，1.5B / 7B 起点是 Math 模型。它们并非只改变参数量、其他条件完全相同的一组规模消融。

因此不能从“70B 低于 32B”直接推出“模型越大越差”，也不能把学生的全部成绩归于这 800k 数据而忽略初始化。

## 4. 为什么 SFT 能传递推理行为？

**机制解释**：

1. 强模型通过生成、RL 探索与选择，提供较高质量的解题轨迹。
2. 学生不必独立发现所有成功轨迹，而是学习这些轨迹的条件分布。
3. 训练后的学生在新问题上，用自己的前缀继续生成；迁移效果要由独立评测决定。

这说明“某种行为最初通过 RL 发现”与“学生必须用 RL 才能获得该行为”不是等价命题。

但文本示范有明确上限：

- 教师错误可能成为标签。
- 学生可能学到反思用语，而非有效纠错。
- 教师轨迹对学生来说可能过长、过难。
- 训练用示范前缀，推理用自己的前缀；偏离后未必会恢复。

这四项都需要验证，不能通过“教师很强”一笔带过。

## 5. 为什么作者比较“32B 直接 RL”和“32B 蒸馏”？

**论文事实**：作者在一个 32B Base 上，用数学、代码与 STEM 数据训练超过 10K RL steps，得到 R1-Zero-Qwen-32B；§4.1 报告它在所列基准上不如 R1-Distill-Qwen-32B。

这支持一个有条件的实践判断：

> 在作者报告的设置中，小模型学习更强教师的精选轨迹，比依赖该小模型自行 RL 探索取得了更好的结果。

不应扩张为：

- 任何小模型上蒸馏都优于 RL。
- RL 永远不能产生超出教师的能力。
- 两条路线已在相同总成本、相同全部数据条件下得到普遍证明。

论文没有给出足以独立重算端到端成本的完整账本。蒸馏若依赖一个已训练好的强教师，边际成本与包含教师研发的总成本不同。

## 6. 为什么“教师负责探索，学生负责利用”只是直觉？

这是有用的机制概括，但不是严格的能力分工定理：

- 教师本身也做过 SFT。
- 学生可以在蒸馏后继续 RL，但不属于本文这组发布结果的训练条件。
- 小模型是否能独立探索成功，取决于起点、任务难度、奖励密度与预算。
- 学生是否泛化，不能只看是否复现了训练题的长回答。

理解蒸馏要同时看**信息来源、学习目标、初始化和评测**，不能只看模型名字里是否带 Distill。

## 7. 如果把它迁移到自己的领域

以下是**未执行的设计建议**：

| 要决定的事 | 需要的证据 |
|---|---|
| 用完整推导还是只用答案 | 相同学生和任务划分下的对照 |
| 保留多少候选 | 每域保留率、独立正确率、成本 |
| 是否允许长轨迹 | 学生上下文、截断率、延迟与收益 |
| 是否继续 RL | 奖励可信度、探索空间、SFT 基线与增量收益 |
| 教师材料是否可用 | 许可、用途、敏感信息和数据血缘 |

工具或教师产生的文本都不是天然真值。先建立独立验证，再考虑规模化生成。
