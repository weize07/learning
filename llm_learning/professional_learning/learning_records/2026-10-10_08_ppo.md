## 1. PPO 在训练流程中做什么？

PPO 是 Proximal Policy Optimization，近端策略优化，是一种强化学习算法，不专属于 LLM。

在常见 LLM 后训练中，希望模型更容易生成高奖励的回答，而不是仅仅模仿一份固定示范。奖励可以来自 Reward Model，也可以来自规则或环境反馈。

```text
训练问题 / 上下文
       ↓
当前策略生成一批回答（rollout）
       ↓
奖励模型 / 规则 / 环境给反馈
       ↓
估计各步优势：结果比原先预期好多少？
       ↓
PPO：更新生成策略，但限制对这批样本的过度优化
       ↓
用更新后的策略再生成新的一批回答
```

常见 RLHF 路线是：SFT → 偏好数据训练 RM → 用 PPO 优化生成策略。但 PPO 也可使用其他奖励，不要求永远先训练独立 RM。

## 2. 先把生成过程看成强化学习

| 概念 | LLM 中对应什么 |
|---|---|
| 状态 $s_t$ | 问题、资料和已生成的回答前缀 |
| 动作 $a_t$ | 选择下一个 token |
| 策略 $\pi_\theta(a_t\mid s_t)$ | 生成模型输出的词表概率 |
| 轨迹 / rollout | 一次生成中的状态、token 与反馈 |
| 奖励 | 回答质量、测试通过、任务完成等反馈 |
| 回报 $G_t$ | 从此步往后的奖励汇总，具体可含折扣等 |

例如：

```text
问题 + 资料 → 选择“通常” → 选择“需要” → …… → 回答结束
                                                   ↓
                                          评价事实与引用
```

奖励经常在整份回答结束后才给出，但策略实际做了多次 token 选择。如何把最终反馈分配到各步，是优势估计要处理的问题；不能自动判断每个 token 都同样导致好结果。

## 3. 奖励与价值模型不是同一个概念

**奖励模型 RM**评价实际生成的回答，例如给完整回答打分。

**价值函数 / Critic**预测某个前缀继续生成时，预期能获得多少回报：

$$
V_\psi(s_t)\approx\mathbb E[G_t\mid s_t]
$$

一种直觉性的优势估计是：

$$
\widehat A_t\approx G_t-V_\psi(s_t)
$$

- 优势为正：实际结果比在该状态下预期的更好，倾向增加这个动作的概率。
- 优势为负：比预期差，倾向降低概率。

实际 PPO 常用 GAE 等估计，不一定直接套上述简单减法。优势是估计量，不是事实正确性标签，也不是 reward 的另一个名字。

Critic 可以与策略共享骨干或使用独立模型，依具体实现；概念上不能把它与 RM 混为一谈。

## 4. 为什么不直接按奖励无限增大概率？

一批回答来自更新前的策略。如果在这批样本上反复大幅更新，策略可能偏离采样时的行为，估计不再可靠，也可能过度利用奖励模型漏洞。

PPO 用概率比来比较：同一个已采样 token，在同一个前缀条件下，新策略比采样策略更倾向生成它多少？

$$
\rho_t(\theta)
=\frac{\pi_\theta(a_t\mid s_t)}
{\pi_{\mathrm{old}}(a_t\mid s_t)}
$$

例如旧概率为 0.2，新概率为 0.3，则 $\rho_t=1.5$；这不是说概率增加了 1.5，而是变成原来的 1.5 倍。

$\pi_{\mathrm{old}}$ 是采集这批 rollout 的策略，更新这批数据时它的概率固定。收集新批次时，可由更新后的策略成为新的采样策略。

## 5. Clip：限制有利方向上的继续奖励

常见 PPO clipped surrogate 是要最大化：

$$
J_{\mathrm{clip}}(\theta)
=\mathbb E_t\left[
\min\left(
\rho_t\widehat A_t,\,
\operatorname{clip}(\rho_t,1-\epsilon,1+\epsilon)\widehat A_t
\right)
\right]
$$

训练代码通常最小化它的负数，再加其他损失项。

先看正优势：取 $\widehat A_t=1$，教学设置 $\epsilon=0.2$：

| 概率比 $\rho_t$ | 未裁剪项 | 裁剪项 | min 后 |
|---:|---:|---:|---:|
| 1.1 | 1.1 | 1.1 | 1.1 |
| 1.5 | 1.5 | 1.2 | 1.2 |

当这个好动作的概率已经明显提高，目标不再因为沿该方向进一步提高概率而获得更多收益。

再看负优势 $\widehat A_t=-1$，概率比降到 0.5：

$$
\min(0.5\times(-1),0.8\times(-1))=-0.8
$$

当这个坏动作的概率已明显降低，继续降低也不再得到额外的该项收益。

**这不是强制把模型最终概率比锁在区间内。** Clip 作用于优化目标，不直接裁剪模型参数或 softmax 输出；参数共享与其他样本梯度仍可能使比例超出区间。

它也不是普通梯度裁剪。梯度裁剪限制梯度大小，PPO clip 修改概率比相关的目标，两者可同时存在。

## 6. 采样旧策略与参考策略：一定要分开

常见 LLM PPO 还加入偏离基础 / SFT 参考模型的惩罚。两种策略角色不同：

| 策略 | 作用 | 是否常随训练更新 |
|---|---|---|
| $\pi_{\mathrm{old}}$ | 这批 rollout 的采样基线，用于 PPO 比率 | 下一轮收集数据时可改变 |
| $\pi_{\mathrm{ref}}$ | 希望不要过度偏离的参考行为 | 常见设置中长期冻结 |

两者起初可能相同，但之后不能直接当成同一模型角色。

KL 正则用于抑制偏离参考策略，例如在特定前缀上衡量词表分布差异。实现也可能将采样 token 的 log 概率比作为惩罚估计，或把惩罚纳入奖励；不保证每一步都是精确全分布 KL。

完整训练通常还涉及 Critic 的价值损失、可选熵项等。PPO clip 与参考 KL 都不保证不遗忘，仍要独立评测业务效果与保留能力。
