# SFT 数据分布与混合采样：从任务目标到可验证配方

## 1. 先分清：训练分布不必等于线上分布

假设业务是从客服文本抽取订单字段。线上可能大量是简单完整订单，但最昂贵的错误来自缺失字段、多订单与矛盾金额。

需要区分：

| 分布 | 决定什么 | 比例由什么确定 |
|---|---|---|
| 目标 / 线上分布 | 希望模型在哪些输入上有效 | 业务流量与目标场景，不由下载的数据条数决定 |
| 训练分布 | 哪些示范被反复用于更新参数 | 数据质量、目标能力、训练预算与实验配方 |
| 评测分布 | 哪些独立输入用于测量效果 | 测量目的：估计线上效果，或专门检查某类风险 / 保留能力 |

训练集可以加强困难样本，但应保留覆盖真实流量的评测，以及专门的边界 / 高风险评测。不能把过采样后的测试分布当成真实线上比例。

```text
业务目标、任务定义与数据分组
        ├→ 独立训练池 → 设计训练配比 → 采样与 SFT → 模型
        │                                           ↓
        └→ 独立验证数据 → 固定评测样本与汇总规则 → 测量
                                                     ↓
                                      根据验证结果调整训练配方

最终测试数据：留出，不能反复用来选择配方
```

训练与评测可以包含相同的“样本类型”，但不能使用同一批样本或泄露的近重复。评测有参考答案也不等于会拿它更新参数。

例如某边界类型线上占 10%，训练时可以有意抽到 40%；测线上总体准确率时仍按目标线上比例估计，而不是跟着训练比例变成 40%。边界专项集可以全是该类型，但它的结果要单独报告。

## 2. 训练池画像：先看有什么示范，再设计训练配比

以下统计对象是经过划分、清洗后的训练池。每条训练样本可保留如下元信息，不必全写进模型输入：

| 维度 | 例子 | 为什么看它 |
|---|---|---|
| 任务 | 抽取、分类、问答、工具调用 | 判断能力覆盖与混合比例 |
| 语言 | 中文、英文、中英混合 | 避免通用英文数据掩盖中文业务 |
| 输入长度 | 短、中、长 | 发现长上下文覆盖不足与截断风险 |
| 有效监督长度 | 答案 token 数 | 评估真正贡献损失的内容量 |
| 难度 / 失败类型 | 缺失字段、矛盾、多个实体 | 针对真实失败而非仅收集简单示范 |
| 输出协议 | JSON schema、工具格式 | 避免互相冲突的标签与模板 |
| 来源 / 分组 | 文档、会话、客户、生成器 | 去重、分组划分、来源追踪 |
| 质量 / 验证 | 人工检查、执行测试、未验证 | 不把数量等同于可靠性 |

应统计联合分布：例如“中文 + 长输入 + 缺失字段”可能完全没有样本，即使单独统计中文、长输入、缺失字段都很多。

难度应依据标注规则、基线表现与人工分析，而不是默认“回答长就是难”。保留失败样本也需要正确目标；错误标签过采样会放大错误。

## 3. 训练中的三种占比：都不是评测权重

### 3.1 原始样本占比

设训练池中的来源 k 有 $N_k$ 条：

$$
q_k=\frac{N_k}{\sum_j N_j}
$$

直接拼接并均匀抽样时，抽到该来源的概率通常与这个比例一致。这里不考虑过滤、截断或自定义采样。

### 3.2 训练采样占比

你可以人为设置来源采样概率 $p_k$：

1. 先按 $p_k$ 选择来源。
2. 再从该来源选择样本。

因此原始有 10% 的业务样本，也可以在训练中占 60% 的抽样次数。实际抽到的次数会随机波动，除非采用固定配额等方式。

### 3.3 监督 token 占比

如果来源 k 的平均有效监督长度为 $\bar\ell_k$，预期监督 token 占比近似为：

$$
t_k\approx
\frac{p_k\bar\ell_k}{\sum_jp_j\bar\ell_j}
$$

长度应在模板、截断、loss mask 等处理之后测量，不是原始字符数，也不是包含全部 prompt 的长度。

**这个公式估计 token 数量占比，不等于精确的梯度贡献。** 损失归约、显式权重、样本难度、批次组成和优化过程都会影响实际贡献。

## 4. 同样条数，为什么长回答可能更“重”？

假设训练中按条数各抽一半：

| 来源 | 抽样占比 | 每条有效监督 token |
|---|---:|---:|
| 业务 JSON 抽取 | 50% | 20 |
| 通用长回答 | 50% | 200 |

每抽两条，平均得到 20 个业务 token 与 200 个通用 token。因此：

$$
t_{\text{业务}}=\frac{20}{20+200}\approx9.09\%
$$

在将有效 token 损失合计后按 token 数归约的目标中，长回答会占更多 token 项。**“各一半问答”不代表“各一半监督内容”。**

不同归约方式：

$$
\mathcal L_{\text{token}}
=\frac{\sum_i\sum_{r=1}^{\ell_i}\mathcal L_{ir}}
{\sum_i\ell_i}
$$

$$
\mathcal L_{\text{sample}}
=\frac1M\sum_{i=1}^{M}
\left(\frac1{\ell_i}\sum_{r=1}^{\ell_i}\mathcal L_{ir}\right)
$$

前者每个有效 token 等权；后者先对每条样本平均，再让样本等权。实际框架可能逐 batch 归约与累计梯度，需核对实现，不能仅凭上式猜测全程目标。

不是必须改成样本等权。先决定业务希望强调什么，再选择采样、归约或权重，并记录实际设置。

## 5. 一个可以讨论的训练配方

以下比例全部是训练采样概率，只决定参数更新时抽哪些示范，不规定验证 / 测试样本比例，也不规定最终指标权重。仅用于说明设计，不是推荐所有业务使用：

| 数据组 | 候选抽样比例 | 目的 |
|---|---:|---|
| 常规业务抽取 | 50% | 学会主要任务与稳定格式 |
| 业务边界样本 | 20% | 缺失、矛盾、多订单等失败类型 |
| 代表性通用指令 | 20% | 观察能否减轻通用能力退化 |
| 相关辅助任务 | 10% | 与业务相关的改写、分类等 |

比例加起来是 100%，但选型前还必须：

- 检查长度与质量，不让长回答在监督量上压倒业务任务。
- 检查公开来源之间的重复，不重复计算同一批示范。
- 确认输出要求在不同任务条件下合理，不混入冲突 schema。
- 保留足够的常规样本，避免模型过度请求澄清或拒答。
- 不混入无关任务，只因为它们容易下载。

通用数据混合只能作为缓解遗忘的候选措施，不保证旧能力保留；也可能分散业务训练预算。下一专题会用双评测明确这种取舍。

### 5.1 为增强目标任务并缓解遗忘，具体怎么采样？

先建立两个独立于验证 / 测试数据的训练池：

- 目标任务池：正确、多样的业务示范，并分层覆盖常规与边界情况。
- 保留能力池：希望继续保留的能力，例如通用指令、问答、中文表达、代码等的代表性示范。不是随意下载一个大通用集合，也不必拿到全部原始预训练语料。

一种可解释的混合采样是：

$$
P_{\text{train}}
=\lambda P_{\text{target}}
+(1-\lambda)P_{\text{retain}}
$$

先按比例选训练池，再在池内按预先设计的任务分层采样。$\lambda$ 表示抽样次数占比，不自动等于监督 token 或梯度占比。

例如比较目标 / 保留池的 100/0、80/20、60/40 三种抽样比例，用来观察取舍；它们只是实验候选，不是通用推荐。每种配方都使用同一套独立验证评测，检查目标收益与各旧能力退化。

实际步骤：

1. 按需要保留的能力划分通用池，设定各组抽样权重，不让最大的来源自然吞掉其他能力。
2. 核对两池的有效监督长度、质量与重复曝光；短业务答案和长通用回答可能使条数比例产生误导。
3. 固定或明确报告训练预算与优化配置，用验证版目标任务集与保留能力集选择配方和 checkpoint。
4. 如果旧能力退化，比较增加相关回放、降低更新强度或减少步数等措施；如果目标任务收益不足，检查标签、覆盖与模型能力，不只是增加目标比例。

混合采样降低遗忘风险，但不保证无遗忘。目标与保留任务可能存在冲突，应明确哪些能力必须保留以及可接受的退化范围。这里的训练配方不规定任何评测比例。

### 5.2 超参数怎样兼顾目标学习与旧能力保留？

核心不是寻找一个“无遗忘学习率”，而是控制更新强度、训练曝光与参数范围，并按双验证选择 checkpoint。学习率小但反复训练很久仍可能遗忘；只看目标训练损失会错过旧能力退化。

| 设置 | 主要作用与取舍 | 如何验证 |
|---|---|---|
| 学习率 | 过高可能更新过猛；过低可能目标适配不足。LoRA 与全量微调的合适范围不同 | 固定其他配置，比较较低 / 基线 / 较高学习率下的目标与保留指标 |
| 步数 / epoch | 更多训练不一定更好，小数据重复曝光可能过拟合或增强任务偏置 | 定期生成评测，选中间 checkpoint，不默认用最后一个 |
| Warmup / 衰减 | 平缓进入更新并逐渐减小步长，帮助优化 | 不把稳定损失误认为能力保留；仍检查双验证 |
| 有效 batch / 梯度累计 | 改变梯度噪声、每次更新的数据量和更新次数 | 记录有效监督 token 与步数；固定 epoch 增大 batch 会减少更新次数 |
| LoRA rank、目标模块与缩放 | 决定可更新容量、位置与强度；rank 小不保证旧能力不变 | 比较实际可训练参数和模块，不只比较 rank 数字 |
| Dropout / weight decay | 正则化可能缓解过拟合，但不直接保证旧知识保留 | 检查目标是否欠拟合、保留能力是否真正改善 |
| 梯度裁剪 | 限制异常大梯度，避免部分不稳定更新 | 不把它当作约束模型整体偏移或防遗忘的方法 |
| 训练池混合 / 损失权重 | 决定目标与保留示范受到多少训练关注 | 核对有效监督量，区分抽样占比与损失权重 |

普通 weight decay 通常将参数向零约束，不等价于将它们约束在预训练权重附近。对于 LoRA，即使缩小适配器参数，也不直接保证所有旧输入的输出接近基础模型。

**一套可操作的调参流程：**

1. 微调前测量目标任务和各保留任务基线，事先定义可接受退化阈值。
2. 先固定可信的数据配方、目标模块与评测；从相似模型 / 任务的已验证训练配置建立基线，不凭模型大小套统一学习率。
3. 小规模比较学习率，例如基线值的 0.5、1、2 倍。这是探索办法，不是通用安全范围。
4. 在每次训练中定期保存并评测多个 checkpoint，覆盖不同曝光量；比较时报告实际步数与监督 token 预算。
5. 目标效果已达标但旧能力继续下降，优先选更早的可行 checkpoint；若没有可行点，再试降低学习率、增加相关回放、调整可训练范围等，并做可归因的对照。
6. 目标与保留指标都很差时，先检查标签、模板、loss mask 与量化基线，不能一概归因于遗忘。

例如下表仅示意模型选择，不表示普遍训练规律。假设某项旧能力最低要求为 78%：

| Checkpoint | 目标准确率 | 该旧能力准确率 | 决策 |
|---|---:|---:|---|
| 基础模型 | 70% | 80% | 基线 |
| 较早 checkpoint | 85% | 79% | 若目标门槛已达，可选 |
| 更晚 checkpoint | 89% | 72% | 旧能力未达要求，不因目标更高就选择 |

多个旧能力应逐项检查。下降 1 个百分点与相对下降 1% 不同，阈值口径要明确；临界差异还要考虑样本量与评测不确定性。

进一步的方法包括对基础 / 教师模型输出加 KL 或蒸馏约束，但会改变训练目标、增加计算，并可能限制新行为学习，下一遗忘专题再展开。它们不是开启就无损的通用开关。

## 6. 怎样实现和调整采样？

### 6.1 先从可解释的组级比例开始

可通过预先构造固定配额的混合数据，或训练时按组概率抽样。二者的随机性、重复方式和“epoch”含义不同，需要记录。

若一个来源有 $N_k$ 条，训练总共抽取 T 条，来源概率为 $p_k$，有放回、组内均匀抽样时，每条样本的预期出现次数为：

$$
\frac{Tp_k}{N_k}
$$

小数据组被大量重复，可能过拟合。重复抽样不创造新的信息；可通过增加可靠多样性、限制重复、减少步数等方式处理。

### 6.2 温度采样作为一种候选

按数据组大小平滑分配：

$$
p_k=\frac{N_k^\alpha}{\sum_jN_j^\alpha},
\qquad 0\le\alpha\le1
$$

- $\alpha=1$：按原始条数比例。
- $\alpha=0$：各非空数据组等概率。
- 中间值：相对提升小组的抽样概率。

这不是生成时的 softmax temperature，也不保证质量更高。数据组怎么定义很重要：把某来源人为拆成许多小组，可能改变总采样权重。

### 6.3 在训练期间检查“实际分布”

记录而非仅保存配置：

- 实际各组样本数、有效监督 token 数与长度分布。
- 被截断、零有效标签、格式错误的样本比例。
- 重复曝光次数、来源与分层覆盖。
- 训练和验证损失按来源拆分，配合真实生成指标。

Packing 用于组织序列，不会自动实现想要的任务平衡；样本边界、监督与归约必须另外核对。

## 7. 独立评测设计：固定测量方式，再比较训练配方

### 7.1 评测样本如何选，指标如何汇总？

评测集的设计回答“要测什么”，与第 5 节的训练配方是两张不同的表：

| 评测套件 | 样本类型与分布 | 如何报告 |
|---|---|---|
| 线上代表集 | 代表目标业务流量；或按类型分层抽样 | 估计线上指标，必要时按目标流量重新加权 |
| 困难 / 边界专项集 | 有意集中在缺失、矛盾、多订单等风险，不要求模拟流量 | 单独报告各风险类型的指标，不直接并入线上分数 |
| 保留能力集 | 来自要保留的旧能力；不要求每类都出现在当前训练配方中 | 按能力报告微调前后变化；若汇总，事先固定权重 |

同一套件内也需保证测试样本与训练独立。如果多个套件存在重叠，明确重叠，不把它们当成独立证据重复计数。

例如只有两个互斥类型，线上普通输入占 90%、边界输入占 10%。为了测准边界效果，评测时各抽 100 条：

- 普通类型准确率 95%。
- 边界类型准确率 60%。

直接平均 200 条，得到 77.5%，它反映这个“各占一半”的评测集，不是线上总体准确率。按线上比例估计为：

$$
\operatorname{Accuracy}_{\text{online}}
=0.9\times0.95+0.1\times0.60
=91.5\%
$$

这个估计要求各类型内的评测样本有代表性，目标比例可靠，且类型划分覆盖目标流量。置信度仍受样本量等影响。即使估计线上准确率较高，也应单独报告边界 60% 的问题；高代价风险可以设置独立门槛，不必只依赖平均值。

**以上 90% / 10% 是目标流量权重，与训练抽样比例无关。** 同样，训练中的监督 token 占比，不决定业务评测中长回答应获得多少权重。

### 7.2 用固定验证集选择配方

先定义可接受条件，例如业务准确率必须达到预定目标，保留任务的退化不得超过业务事先定义的范围。具体阈值由任务风险与基线决定，不套用通用百分比。

可以比较：

| 实验 | 主要问题 |
|---|---|
| 不微调的 prompt 基线 | SFT 是否真的必要？ |
| 只用业务数据 | 能得到多少目标收益，会损失哪些能力？ |
| 业务 + 通用数据 | 是否改善保留能力，是否牺牲目标收益？ |
| 增加边界样本 | 边界收益是否伴随常规任务误拒答？ |

如果目的是比较配方，在同一次对照中尽量固定基础模型、LoRA 配置、生成配置与预算口径。预算可以按优化步数或有效监督 token 等定义，但两者不一定同时相等；报告实际差异。

在同一次配方对照中，固定验证输入、参考答案、各套件指标与汇总规则，不随训练配比改变评测配比。否则难以判断分数变化来自模型还是测量方式。

上述三类评测都可分别建立验证版与最终测试版。调参用验证版，最终测试版不反复用来挑配方。根据验证坏例补训练数据时，使用独立采集或生成的同类型样本，不直接把验证题及近重复加入训练；若加入，原验证题就不再是独立测量证据。

检查分组划分与近重复泄露。差异较小时考虑随机种子、评测样本量与不确定性，不因一个小分数差就宣布最佳配方。

### 7.3 为评测中立、尽量无偏，具体怎么采样？

首先定义要估计的量。不存在对所有目标都“中立”的统一样本分布：

- 测线上平均效果：目标是特定业务流量上的期望表现。
- 测各能力表现：目标是预先定义的任务 / 语言 / 难度范围中的表现。
- 测微调遗忘：目标是同一组旧能力输入上，微调后相对基础模型的变化。

**线上效果**可从代表性的流量时间窗随机抽取请求；若罕见类型太少，可分层随机抽样，再按目标流量权重汇总。固定互斥且覆盖目标的类型，组内随机抽样，已知类型比例为 $\pi_k$，则对于准确率等逐样本可加指标：

$$
\widehat S_{\text{online}}=\sum_k\pi_k\widehat S_k
$$

其中 $\widehat S_k$ 是第 k 类的样本平均。层内抽样有代表性、比例正确等条件下，该估计可无偏；样本量决定精度。F1 等非线性指标不能普遍直接套用加权平均，应按指标定义汇总相应统计量。

若请求或用户的抽取概率不同，应匹配所定义的评估单位并处理抽样权重。按用户均匀抽样与按请求均匀抽样，估计的目标可能不同；不能默认等价。

**保留能力评测**在各预定能力内随机抽取独立样本，保留能力间固定配额可以提高覆盖。逐能力报告基础模型与微调模型在相同输入上的差异；如取宏平均，各能力等权只是事先选定的评测目标，不代表线上分布，也不是天然更无偏。

最低要求：

1. 评测题不由某个候选模型答对 / 答错来筛选；专项失败集应明确标记，不能代表无条件总体。
2. 训练与评测按必要的文档 / 会话等分组隔离，并检查近重复；有相关样本时，置信区间也应考虑相关性，而不是默认全部独立。
3. 同一次模型比较使用相同输入、评分规则与事先固定的生成设置；人工或 LLM 评分可匿名、随机答案顺序，降低偏好与位置偏差，但不保证消除所有偏差。
4. 只用验证集调参，最终测试集留出；对同一输入比较两个模型属于配对比较，可报告差异及不确定性。
5. 记录目标时间窗、抽样方法、类型权重、样本量、随机种子与版本；分布漂移后重新评估，不随某个模型结果临时修改权重。

一句话：**训练采样主动偏向希望学习的能力；评测采样忠实于事先定义的测量目标，并用独立数据与正确权重估计。公平比较和统计无偏不是同一个概念，两方面都要处理。**
